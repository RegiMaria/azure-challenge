## 🔷 Sobre esse repositório

Esse repositório existe pra me ajudar a organizar meus estudos de Microsoft Azure. Aqui eu reúno minhas anotações, exercícios e evidências enquanto percorro as trilhas oficiais de estudo da Microsoft — das certificações Fundamentals até as práticas mais aplicadas (Applied Skills).

## 🔷 Pra que serve o repositório
Documentar meu progresso de estudo, certificação por certificação, módulo a módulo
Servir de material de revisão antes de cada exame
Ser referência pública (portfólio) mostrando disciplina e organização no aprendizado de Azure
Guardar num único lugar o caminho que percorri: 
```
fundamentos → dados → prática aplicada
```

## 🔷 Conteúdo do repositório

| Pasta                          | O que tem dentro                                                                                                                                     | Link                                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 📁 **AZ-900 (Fundamentos)**    | Trilha de fundamentos gerais de computação em nuvem e da plataforma Microsoft Azure - conceitos de nuvem, arquitetura, governança e projetos guiados | [Acessar pasta](https://github.com/RegiMaria/azure-challenge/tree/main/AZ-900%20%28Fundamentos%29) |
| 📁 **DP-900 (Fundamentos-II)** | Trilha de fundamentos de dados no Azure - dados relacionais, não relacionais e analytics                                                             | [Acessar pasta](https://github.com/RegiMaria/azure-challenge/tree/main/DP-900%28Fundamentos-II%29) |
| 📁 **Applied-Skills**          | Credenciais práticas da Microsoft (Applied Skills) que complementam as trilhas de fundamentos com labs reais no Azure/Fabric                         | [Acessar pasta](https://github.com/RegiMaria/azure-challenge/tree/main/Applied-Skills)             |



> 💡 Cada pasta tem seu próprio README com o detalhamento dos módulos, datas de conclusão e links diretos para a Microsoft Learn.
