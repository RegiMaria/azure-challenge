## 🔷 Sobre DP-900
Aborda conceitos e serviços de dados DP-900 (Microsoft Azure Data Fundamentals)

Foco principal: Fundamentos de dados dentro do ambiente em nuvem.

O que cai na prova: Conceitos de dados relacionais e não relacionais, cargas de trabalho transacionais e analíticas, e serviços de banco de dados do Azure (como SQL e Cosmos DB).

Para quem é: Pessoas que desejam iniciar uma carreira na área de dados, engenharia de dados ou análise

## 🔷 O que é esse repositório

Este repositório reúne minhas anotações, exercícios e evidências de estudo enquanto percorro a trilha oficial da Microsoft **"Introduction to Cloud Infrastructure"**, série de 4 partes que prepara para a certificação **AZ-900: Microsoft Azure Fundamentals** - o ponto de entrada oficial da Microsoft para quem está começando na nuvem.

## 🔷 Pra que serve o repositório

- Documentar meu progresso de estudo módulo a módulo
- Servir de material de revisão antes do exame AZ-900
- Ser referência pública (portfólio) mostrando disciplina e organização no aprendizado de Azure
