<h1 align="center">Microsoft Applied Skills: Azure Security and Monitoring</h1>

Este repositório documenta meu progresso na trilha de estudos da Microsoft Learn para a credencial **Microsoft Applied Skills: Get started with cloud security and monitoring tasks**.

[Microsoft Applied Skills: Get started with cloud security and monitoring tasks](https://learn.microsoft.com/en-us/credentials/applied-skills/get-started-with-cloud-security-and-monitoring-tasks/?wt.mc_id=studentamb_625645)

---

## Sobre a credencial

> Para obter essa credencial de Habilidades Aplicadas da Microsoft, os aprendizes demonstram a capacidade de configurar segurança, governança e monitoramento para o Azure.

- **Nível:** Iniciante
- **Produto:** Azure Firewall · Azure Key Vault · Azure Monitor
- **Função:** Engenheiro de segurança
- **Assunto:** Segurança na nuvem
- **Formato da avaliação:** Laboratório interativo (hands-on), sem múltipla escolha
- **Duração da avaliação:** até 2 horas
- **Idioma da avaliação:** Inglês

> ⚠️ A avaliação usa um laboratório interativo. O carregamento do laboratório pode levar alguns minutos, e após iniciá-lo é necessário aguardar 72 horas para iniciá-lo novamente. Movimentos do mouse e textos digitados durante o laboratório são gravados para fins de qualidade. [Saiba mais](https://learn.microsoft.com/credentials/support/assessment-duration-lab-experience?wt.mc_id=studentamb_625645)

**Habilidades avaliadas:**
- Executar tarefas básicas de proteção de carga de trabalho na nuvem (CWPP)
- Executar tarefas básicas de gerenciamento de chaves
- Executar tarefas básicas de configuração de firewall
- Executar tarefas básicas de monitoramento

## Módulos

### 1. [Configurar e gerenciar a proteção contra ameaças usando o Microsoft Defender para Nuvem](https://learn.microsoft.com/pt-br/training/modules/microsoft-defender-cloud-threat-protection/?wt.mc_id=studentamb_625645)
- **Duração:** 3 h 20 min
- **Unidades:** 35
- **Resumo:** configuração e gerenciamento da proteção contra ameaças (CWPP) usando o Microsoft Defender para Nuvem.

### 2. [Introdução ao Firewall do Azure](https://learn.microsoft.com/pt-br/training/modules/introduction-azure-firewall/?wt.mc_id=studentamb_625645)
- **Duração:** 48 min
- **Unidades:** 7
- **Resumo:** conceitos e configuração básica do Firewall do Azure.

### 3. [Criar e configurar um workspace do Log Analytics](https://learn.microsoft.com/pt-br/training/modules/create-configure-log-analytics-workspace/?wt.mc_id=studentamb_625645)
- **Duração:** 28 min
- **Unidades:** 7
- **Resumo:** criação e configuração de um workspace do Log Analytics para monitoramento.

**Duração total do Learning Path:** 4 h 36 min *(todas as avaliações dos módulos aprovadas)*
