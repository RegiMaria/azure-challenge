<h1 align="center"> Azure Guided Projects </h1>

Este repositório documenta meu progresso no **Learning Path** da Microsoft Learn:

[Introduction to Cloud Infrastructure: Apply Azure skills in guided projects](https://learn.microsoft.com/en-us/training/paths/introduction-cloud-infrastructure-apply-azure-skills-guided-projects/?wt.mc_id=studentamb_625645)

Este learning path contém 8 módulos práticos (projetos guiados) que, juntos, preparam para o exame **AZ-900: Microsoft Azure Fundamentals**:

1. [Módulo 1 - Guided project: Deploy a static website with Azure Blob Storage](https://learn.microsoft.com/en-us/training/modules/guided-project-deploy-static-website-blob-storage/?wt.mc_id=studentamb_625645)
2. [Módulo 2 - Guided project: Organize and protect resources with tags and locks](https://learn.microsoft.com/en-us/training/modules/guided-project-organize-resources-tags-locks/?wt.mc_id=studentamb_625645)
3. [Módulo 3 - Guided Project: Build a simple website endpoint with Azure Functions](https://learn.microsoft.com/en-us/training/modules/guided-project-build-basic-website-endpoint-with-functions/?wt.mc_id=studentamb_625645)
4. [Módulo 4 - Guided Project: Set up new employee access (Entra ID and RBAC)](https://learn.microsoft.com/en-us/training/modules/guided-project-new-employee-access/?wt.mc_id=studentamb_625645)
5. [Módulo 5 - Guided project: Share files securely](https://learn.microsoft.com/en-us/training/modules/guided-project-share-files-securely/?wt.mc_id=studentamb_625645)
6. [Módulo 6 - Guided project: Set up cost guardrails in Azure](https://learn.microsoft.com/en-us/training/modules/guided-project-cost-guardrails/?wt.mc_id=studentamb_625645)
7. [Módulo 7 - Guided project: Monitor Azure with Service Health and Activity Log alerts](https://learn.microsoft.com/en-us/training/modules/guided-project-monitor-service-health-activity-alerts/?wt.mc_id=studentamb_625645)
8. [Módulo 8 - Guided project: Manage Azure resources with Cloud Shell and the Azure CLI](https://learn.microsoft.com/en-us/training/modules/guided-project-manage-resources-cloud-shell-cli/?wt.mc_id=studentamb_625645)

- **Módulos:** 8
- **Nível:** Beginner
- **Produto:** Azure

**Tópicos:** [Architecture](https://learn.microsoft.com/en-us/training/browse/?subjects=architecture&resource_type=learning%20path&wt.mc_id=studentamb_625645) · [Cloud computing](https://learn.microsoft.com/en-us/training/browse/?subjects=cloud-computing&resource_type=learning%20path&wt.mc_id=studentamb_625645) · [Technical infrastructure](https://learn.microsoft.com/en-us/training/browse/?subjects=infrastructure&resource_type=learning%20path&wt.mc_id=studentamb_625645)

## Módulos

### 1. [Guided project: Deploy a static website with Azure Blob Storage](https://learn.microsoft.com/en-us/training/modules/guided-project-deploy-static-website-blob-storage/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** projeto guiado sobre hospedar um site estático usando o Azure Blob Storage e atualizar seu conteúdo.

### 2. [Guided project: Organize and protect resources with tags and locks](https://learn.microsoft.com/en-us/training/modules/guided-project-organize-resources-tags-locks/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** projeto guiado que ajuda a organizar recursos do Azure com tags e protegê-los contra exclusão acidental usando locks.

### 3. [Guided Project: Build a simple website endpoint with Azure Functions](https://learn.microsoft.com/en-us/training/modules/guided-project-build-basic-website-endpoint-with-functions/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** introduz a hospedagem serverless criando um endpoint de função e validando as respostas.

### 4. [Guided Project: Set up new employee access (Entra ID and RBAC)](https://learn.microsoft.com/en-us/training/modules/guided-project-new-employee-access/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** ajuda a implementar acesso de privilégio mínimo (least-privilege) para um novo usuário usando Entra ID e RBAC.

### 5. [Guided project: Share files securely](https://learn.microsoft.com/en-us/training/modules/guided-project-share-files-securely/?wt.mc_id=studentamb_625645)
- **Duração:** 49 min
- **Unidades:** 10
- **XP:** 1100
- **Resumo:** ensina compartilhamento seguro e temporário de arquivos usando blob storage, stored access policies e tokens SAS.

### 6. [Guided project: Set up cost guardrails in Azure](https://learn.microsoft.com/en-us/training/modules/guided-project-cost-guardrails/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** ajuda a reduzir o risco de gastos implementando guardrails (barreiras) de custo no Azure.

### 7. [Guided project: Monitor Azure with Service Health and Activity Log alerts](https://learn.microsoft.com/en-us/training/modules/guided-project-monitor-service-health-activity-alerts/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** ajuda a construir uma linha de base de monitoramento inicial usando serviços gratuitos de alerta do Azure.

### 8. [Guided project: Manage Azure resources with Cloud Shell and the Azure CLI](https://learn.microsoft.com/en-us/training/modules/guided-project-manage-resources-cloud-shell-cli/?wt.mc_id=studentamb_625645)
- **Duração:** 43 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** apresenta o Cloud Shell e a Azure CLI como ferramentas para criar e gerenciar recursos do Azure via linha de comando.

**XP total do learning path:** 7400 XP *(todos os projetos guiados concluídos)*
