<h1 align="center"> Azure Management and Governance </h1>

Este repositório documenta meu progresso no **Learning Path** da Microsoft Learn:

[Introduction to Cloud Infrastructure: Describe Azure management and governance](https://learn.microsoft.com/en-us/training/paths/describe-azure-management-governance/?wt.mc_id=studentamb_625645)

Este learning path contém 4 módulos que, juntos, preparam para o exame **AZ-900: Microsoft Azure Fundamentals**:

1. [Módulo 1 - Describe cost management in Azure](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/?wt.mc_id=studentamb_625645)
2. [Módulo 2 - Describe features and tools in Azure for governance and compliance](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-azure-for-governance-compliance/?wt.mc_id=studentamb_625645)
3. [Módulo 3 - Describe features and tools for managing and deploying Azure resources](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-manage-deploy-azure-resources/?wt.mc_id=studentamb_625645)
4. [Módulo 4 - Describe monitoring tools in Azure](https://learn.microsoft.com/en-us/training/modules/describe-monitoring-tools-azure/?wt.mc_id=studentamb_625645)

## Sobre o Learning Path

> New to the cloud? Este learning path ensina conceitos básicos de cloud, oferece uma visão geral simplificada de diversos serviços do Azure e guia com exercícios práticos para implantar os primeiros serviços gratuitamente.

- **Duração total:** 1 hr 21 min
- **Tipo:** Learning Path
- **Módulos:** 4
- **Nível:** Beginner
- **Produto:** Azure
- **Função:** Administrator · Developer · DevOps Engineer · Solution Architect
- **Pré-requisitos:** familiaridade básica com termos e conceitos de TI

**Outros learning paths da série:**
[Parte 1 - Describe cloud concepts](https://learn.microsoft.com/en-us/training/paths/microsoft-azure-fundamentals-describe-cloud-concepts/?wt.mc_id=studentamb_625645) · [Parte 2 - Describe Azure architecture and services](https://learn.microsoft.com/en-us/training/paths/azure-fundamentals-describe-azure-architecture-services/?wt.mc_id=studentamb_625645) · **Parte 3 - Describe Azure management and governance** *(este repositório)* · [Parte 4 - Apply Azure skills in guided projects](https://learn.microsoft.com/en-us/training/paths/introduction-cloud-infrastructure-apply-azure-skills-guided-projects/?wt.mc_id=studentamb_625645)

**Tópicos:** [Cloud computing](https://learn.microsoft.com/en-us/training/browse/?subjects=cloud-computing&resource_type=learning%20path&wt.mc_id=studentamb_625645) · [Compliance](https://learn.microsoft.com/en-us/training/browse/?subjects=compliance&resource_type=learning%20path&wt.mc_id=studentamb_625645)

## Módulos

### 1. [Describe cost management in Azure](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/?wt.mc_id=studentamb_625645)
- **Duração:** 27 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** explora métodos para estimar, acompanhar e gerenciar custos no Azure.

### 2. [Describe features and tools in Azure for governance and compliance](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-azure-for-governance-compliance/?wt.mc_id=studentamb_625645)
- **Duração:** 19 min
- **Unidades:** 7
- **XP:** 800
- **Resumo:** apresenta as ferramentas que ajudam na governança e na conformidade dentro do Azure.

### 3. [Describe features and tools for managing and deploying Azure resources](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-manage-deploy-azure-resources/?wt.mc_id=studentamb_625645)
- **Duração:** 22 min
- **Unidades:** 6
- **XP:** 700
- **Resumo:** cobre as ferramentas que ajudam a gerenciar recursos do Azure e on-premises.

### 4. [Describe monitoring tools in Azure](https://learn.microsoft.com/en-us/training/modules/describe-monitoring-tools-azure/?wt.mc_id=studentamb_625645)
- **Duração:** 13 min
- **Unidades:** 6
- **XP:** 700
- **Resumo:** cobre as ferramentas que podem ser usadas para monitorar seu ambiente Azure.

**XP total do learning path:** 3100 XP *(todas as avaliações dos módulos aprovadas)*
