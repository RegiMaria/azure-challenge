<h1 align="center">Engenheiro DevOps</h1>

Este repositório documenta minha jornada de estudos na Microsoft Learn rumo à trilha de **Engenheiro DevOps**, organizada em 4 níveis: iniciante, intermediário, avançado e a credencial Microsoft Applied Skills.

> 📄 Jornada oficial (PDF): [Credential Journey - DevOps Engineer](https://arch-center.azureedge.net/Credentials/Credential-Journey-DevOps-Engineer.pdf#zoom=45%)
