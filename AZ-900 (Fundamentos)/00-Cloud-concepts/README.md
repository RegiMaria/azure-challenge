# 00 - Cloud Concepts

## Introduction to Cloud Infrastructure: Describe cloud concepts

Este repositório documenta meu progresso no **Learning Path** da Microsoft Learn:
[Introduction to Cloud Infrastructure: Describe cloud concepts](https://learn.microsoft.com/en-us/training/paths/microsoft-azure-fundamentals-describe-cloud-concepts/)

Este é o **Part 1** de uma série de 4 learning paths que, juntos, preparam para o exame **AZ-900: Microsoft Azure Fundamentals**:

1. **Part 1** - Introduction to Cloud Infrastructure: Describe cloud concepts *(este repositório)*

3. [Part 3 - Describe Azure management and governance](https://learn.microsoft.com/en-us/training/paths/describe-azure-management-governance/)
4. [Part 4 - Apply Azure skills in guided projects](https://learn.microsoft.com/en-us/training/paths/introduction-cloud-infrastructure-apply-azure-skills-guided-projects/)

## Sobre o Learning Path

> New to the cloud? Este learning path ensina conceitos básicos de cloud, oferece uma visão geral simplificada de diversos serviços do Azure e guia com exercícios práticos para implantar os primeiros serviços gratuitamente.

- **Duração total:** 56 min
- **Tipo:** Learning Path
- **Módulos:** 3
- **Pré-requisitos:** familiaridade básica com termos e conceitos de TI

**Tópicos:** [Architecture](https://learn.microsoft.com/en-us/training/browse/?subjects=architecture&resource_type=learning%20path) · [Cloud computing](https://learn.microsoft.com/en-us/training/browse/?subjects=cloud-computing&resource_type=learning%20path) · [Technical infrastructure](https://learn.microsoft.com/en-us/training/browse/?subjects=infrastructure&resource_type=learning%20path)

**Link geral do learning path:** https://learn.microsoft.com/en-us/training/paths/microsoft-azure-fundamentals-describe-cloud-concepts/

## Módulos

### 1. [Describe cloud computing](https://learn.microsoft.com/en-us/training/modules/describe-cloud-compute/)
- **Duração:** 24 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** introdução à computação em nuvem - conceitos de cloud, modelos de implantação e o modelo de responsabilidade compartilhada.

### 2. [Describe the benefits of using cloud services](https://learn.microsoft.com/en-us/training/modules/describe-benefits-use-cloud-services/)
- **Duração:** 19 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** introdução aos benefícios que a computação em nuvem pode oferecer para você ou sua organização.

### 3. [Describe cloud service types](https://learn.microsoft.com/en-us/training/modules/describe-cloud-service-types/)
- **Duração:** 13 min
- **Unidades:** 6
- **XP:** 700
- **Resumo:** os diferentes tipos de serviços de cloud, com casos de uso e benefícios de cada tipo.

**XP total do learning path:** 900 XP *(todas as avaliações dos módulos aprovadas)*
