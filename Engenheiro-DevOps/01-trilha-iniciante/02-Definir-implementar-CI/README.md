<h1 align="center">Definir e implementar a integração contínua</h1>

Este repositório documenta meu progresso na trilha de estudos da Microsoft Learn **Definir e implementar a integração contínua**, parte da jornada Engenheiro DevOps.

[Definir e implementar a integração contínua](https://learn.microsoft.com/pt-br/training/paths/az-400-define-implement-continuous-integration/?wt.mc_id=studentamb_625645)

## Sobre a trilha

> Aprenda a criar fluxos de trabalho de integração contínua (CI) usando o GitHub Actions, automatizando builds, testes e validações a cada alteração no código.

## Learning Path

- **Duração total:** 1 h 21 min
- **Tipo:** Learning Path
- **Módulos:** 1

---

## Módulos

- **Duração:** 1 h 21 min
- **Unidades:** 8
- **Resumo:** saiba como criar fluxos de trabalho para adicionar CI (integração contínua) aos seus projetos.
