<h1 align="center">Gerenciar controle do código-fonte</h1>

Este repositório documenta meu progresso na trilha de estudos da Microsoft Learn **Gerenciar controle do código-fonte**, parte da jornada Engenheiro DevOps.

[Gerenciar controle do código-fonte](https://learn.microsoft.com/pt-br/training/paths/az-400-manage-source-control/?wt.mc_id=studentamb_625645)

---

## Sobre a trilha

> Aprenda a gerenciar o controle de código-fonte usando o GitHub: migração e upload de repositórios, pull requests, resolução de conflitos, InnerSource, segurança, automação com GitHub Apps e GitHub Script, e fluxos de entrega contínua com GitHub Actions.

**Visão rápida**
- **Nível:** Iniciante
- **Produto:** Azure · GitHub
- **Função:** Engenheiro de DevOps · Administrador · Desenvolvedor · Arquiteto de solução

## Learning Path

- **Duração total:** 15 h
- **Tipo:** Roteiro de aprendizagem (Learning Path)
- **Módulos:** 14
- **Progresso atual:** 1 de 14 módulos concluídos · 13 h 59 min restantes

---

## Módulos

### 1. [Introdução ao GitHub](https://learn.microsoft.com/pt-br/training/modules/introduction-to-github/?wt.mc_id=studentamb_625645)
- **Duração:** 1 h 45 min
- **Unidades:** 8
- **Resumo:** aprenda a usar os principais recursos do GitHub, incluindo problemas, notificações, branches, confirmações e solicitações de pull.

### 2. [Migrar seu repositório usando as práticas recomendadas do GitHub](https://learn.microsoft.com/pt-br/training/modules/migrate-repository-github/?wt.mc_id=studentamb_625645)
- **Duração:** 43 min
- **Unidades:** 5
- **Resumo:** saiba como mover seu projeto existente para o GitHub de um sistema de controle de versão herdado.

### 3. [Carregar seu projeto usando as práticas recomendadas do GitHub](https://learn.microsoft.com/pt-br/training/modules/upload-project-github/?wt.mc_id=studentamb_625645)
- **Duração:** 43 min
- **Unidades:** 5
- **Resumo:** saiba como carregar seu projeto existente no GitHub.

### 4. [Gerenciar alterações de repositório usando solicitações de pull no GitHub](https://learn.microsoft.com/pt-br/training/modules/manage-changes-pull-requests-github/?wt.mc_id=studentamb_625645)
- **Duração:** 56 min
- **Unidades:** 5
- **Resumo:** saiba como gerenciar alterações na origem do repositório usando solicitações de pull.

### 5. [Solucionar confirmações concorrentes usando a resolução de conflitos de mesclagem no GitHub](https://learn.microsoft.com/pt-br/training/modules/resolve-merge-conflicts-github/?wt.mc_id=studentamb_625645)
- **Duração:** 52 min
- **Unidades:** 5
- **Resumo:** saiba como solucionar confirmações sobrepostas entre branches usando a resolução de conflitos de mesclagem.

### 6. [Pesquisar e organizar o histórico do repositório usando o GitHub](https://learn.microsoft.com/pt-br/training/modules/search-organize-repository-history-github/?wt.mc_id=studentamb_625645)
- **Duração:** 38 min
- **Unidades:** 5

### 7. [Gerenciar um programa InnerSource usando o GitHub](https://learn.microsoft.com/pt-br/training/modules/manage-innersource-program-github/?wt.mc_id=studentamb_625645)
- **Duração:** 50 min
- **Unidades:** 5

### 8. [Comunicar-se efetivamente no GitHub usando Markdown](https://learn.microsoft.com/pt-br/training/modules/communicate-using-markdown/?wt.mc_id=studentamb_625645)
- **Duração:** 1 h 6 min
- **Unidades:** 5

### 9. [Manter um repositório seguro com as melhores práticas do GitHub](https://learn.microsoft.com/pt-br/training/modules/maintain-secure-repository-github/?wt.mc_id=studentamb_625645)
- **Duração:** 35 min
- **Unidades:** 6

### 10. [Automatizar processos de DevOps usando Aplicativos do GitHub](https://learn.microsoft.com/pt-br/training/modules/automate-devops-github-apps/?wt.mc_id=studentamb_625645)
- **Duração:** 43 min
- **Unidades:** 6

### 11. [Automatizar o GitHub usando o GitHub Script](https://learn.microsoft.com/pt-br/training/modules/automate-github-using-github-script/?wt.mc_id=studentamb_625645)
- **Duração:** _não informada_
- **Unidades:** _não informada_

### 12. [Gerenciar a entrega de software usando um fluxo de trabalho baseado em versão no GitHub](https://learn.microsoft.com/pt-br/training/modules/release-based-workflow-github/?wt.mc_id=studentamb_625645)
- **Duração:** 1 h 44 min
- **Unidades:** 5

### 13. [Criar fluxos de trabalho de integração contínua usando o GitHub Actions](https://learn.microsoft.com/pt-br/training/modules/github-actions-ci/?wt.mc_id=studentamb_625645)
- **Duração:** 1 h 21 min
- **Unidades:** 8

### 14. [Criar e implantar aplicativos no Azure com o GitHub Actions](https://learn.microsoft.com/pt-br/training/modules/github-actions-cd/?wt.mc_id=studentamb_625645)
- **Duração:** 2 h 59 min
- **Unidades:** 8

**Duração total do Learning Path:** 15 h *(1 de 14 módulos concluídos)*
