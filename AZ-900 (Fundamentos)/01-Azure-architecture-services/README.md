## Sobre o Learning Path

> New to the cloud? Este learning path ensina conceitos básicos de cloud, oferece uma visão geral simplificada de diversos serviços do Azure e guia com exercícios práticos para implantar os primeiros serviços gratuitamente.

- **Duração total:** 56 min
- **Tipo:** Learning Path
- **Módulos:** 5
- **Pré-requisitos:** familiaridade básica com termos e conceitos de TI

**Tópicos:** [Architecture](https://learn.microsoft.com/en-us/training/browse/?subjects=architecture&resource_type=learning%20path&wt.mc_id=studentamb_625645) · [Cloud computing](https://learn.microsoft.com/en-us/training/browse/?subjects=cloud-computing&resource_type=learning%20path&wt.mc_id=studentamb_625645) · [Technical infrastructure](https://learn.microsoft.com/en-us/training/browse/?subjects=infrastructure&resource_type=learning%20path&wt.mc_id=studentamb_625645)

**Link geral do learning path:** [Introduction to Cloud Infrastructure: Describe Azure architecture and services](https://learn.microsoft.com/en-us/training/paths/azure-fundamentals-describe-azure-architecture-services/?wt.mc_id=studentamb_625645)

## Módulos
  
### 1. [Describe the core architectural components of Azure](https://learn.microsoft.com/en-us/training/modules/describe-core-architectural-components-of-azure/?wt.mc_id=studentamb_625645)
- **Duração:** 28 min
- **Unidades:** 7
- **XP:** 800
- **Resumo:** explica os componentes básicos de infraestrutura do Microsoft Azure — a infraestrutura física e como os recursos são gerenciados.

### 2. [Describe Azure compute services](https://learn.microsoft.com/en-us/training/modules/describe-azure-compute-networking-services/?wt.mc_id=studentamb_625645)
- **Duração:** 33 min
- **Unidades:** 9
- **XP:** 1000
- **Resumo:** foca nos principais serviços de computação do Azure e quando usar cada opção.

### 3. [Describe Azure networking services](https://learn.microsoft.com/en-us/training/modules/describe-azure-networking-services/?wt.mc_id=studentamb_625645)
- **Duração:** 24 min
- **Unidades:** 7
- **XP:** 800
- **Resumo:** apresenta os recursos de rede do Azure para comunicação segura entre recursos do Azure, ambientes on-premises e clientes conectados à internet.

### 4. [Describe Azure storage services](https://learn.microsoft.com/en-us/training/modules/describe-azure-storage-services/?wt.mc_id=studentamb_625645)
- **Duração:** 36 min
- **Unidades:** 8
- **XP:** 900
- **Resumo:** introduz o armazenamento no Azure, incluindo os diferentes tipos de armazenamento e como uma infraestrutura distribuída pode tornar seus dados mais resilientes.

### 5. [Describe Azure identity, access, and security](https://learn.microsoft.com/en-us/training/modules/describe-azure-identity-access-security/?wt.mc_id=studentamb_625645)
- **Duração:** 47 min
- **Unidades:** 12
- **XP:** 1300
- **Resumo:** aborda alguns dos métodos de autorização e autenticação disponíveis no Azure.

**XP total do learning path:** 4800 XP *(todas as avaliações dos módulos aprovadas)*
